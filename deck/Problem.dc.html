The Problem

Idle servers still draw almost full power

A physical machine's power draw does not scale down with how little work it's doing — and the base paper's scheduler only ever decides once, then never looks back.

Only 10% of the work, but still 77% of the power bill — using the base paper's own idle/peak power figures (175W–250W per host).
“An algorithm that assigns tasks once and walks away can't fix this — by the time load has shifted, nobody is watching.”
