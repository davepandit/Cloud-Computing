What We Changed

Same paper, same goals — different assumptions about the world

ROA = Revolution Optimization Algorithm, the paper's method  ·  MBFD = Modified Best-Fit Decreasing, a well-known bin-packing heuristic (not from the paper)

Aspect Base paper (ROA) Our approach
Scheduling model One-shot: assign a batch of tasks once, then stop Continuous loop: monitor → migrate → consolidate → power down, on repeat
Core algorithm ROA — a population-based metaheuristic, needs many iterations to converge MBFD bin-packing — fast enough to re-run every control-loop cycle
Objective function Energy + temperature + carbon (3 fixed weighted terms) Same 3 terms + a 4th migration-cost term; a task only moves if it's worth it
Validation CloudSim simulation only Offline simulator + a real Kubernetes cluster with real pods
Node power action Not modeled — the paper never touches power state Idle nodes are actually stopped and restarted (real Docker containers)
Baselines compared GA, PSO, ACO Naive round-robin, tested ourselves — GA/PSO/ACO reproduction is planned, not done yet
